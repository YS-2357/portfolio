# Glossary

- static site: frontend served without SSR/runtime backend requirement
- content-driven: page content originates from repo-managed markdown/data
- landing page: the main portfolio entry experience
- Firebase Hosting: deployment target for this repo
- private asset: a file kept in the repo but not exposed publicly
